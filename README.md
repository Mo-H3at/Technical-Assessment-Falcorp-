- Flutter version: 3.50 (channel stable)
- VsCode (IDE used to running and installation)

- In the project and separately you will find the json files that you will need to insert in the asset folder
- the json folder must be renamed to 'data_files' for the seeding to find it

## Flow
- Sign in = Enter any of the test emails provided or one you've signed up to enter the main page
- Sign Up = Enter the name, email and select your membership tier to create new user who can be used to sign in
- Home page = displays a grid of the features that are accompanied by the membership tier
- Membership page = gives a list of all features with explanations
- Upgrade Page = Displays a slider of membership options you wish to upgrade to
- Setting >> Update profile = allows user to update their name or email
- Setting >> Sign Out = allows the user to sign out of the app
- Setting >> Delete profile = deletes the users profile and also signs them out
